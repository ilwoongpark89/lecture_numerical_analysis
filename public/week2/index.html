연산자와 우선순위 — 한눈에

MATLAB은 산술 → 관계 → 논리 순으로 우선순위가 낮아진다. 특히 산술 안에서 거듭제곱 $\wedge$ 이 곱셈·나눗셈보다, 곱셈이 덧셈보다 먼저 계산된다.

산술 연산자
기호뜻예 → 결과
+ -덧셈·뺄셈10-6 → 4
* /곱·나눗셈10/3 → 3.3333
^거듭제곱2^10 → 1024
mod나머지(양수)mod(7,3) → 1
관계 · 논리 연산자
기호뜻예 → 결과
==같다5==5 → 1
~=같지 않다5~=3 → 1
& |AND · OR1&0 → 0
&& ||단락 평가스칼라 전용
우선순위 한 줄
$\wedge \;\to\; *,/ \;\to\; +,- \;\to\; \lt,\gt,== \;\to\; \&\&,||$. 헷갈리면 괄호로 명시한다.
직접 계산연산 우선순위 예측 · 자동 채점
직접계산 · 우선순위

MATLAB에서 2 + 3 * 4^2 를 실행하면 어떤 값이 나오는가? 우선순위는 거듭제곱 → 곱셈 → 덧셈 순이다.

$4^2=16$$3\times16=48$$2+48$
Step 1 · 거듭제곱
$$ 4\wedge 2 = 16 $$
Step 2 · 곱셈 → 덧셈
$$ 3\times16 = 48,\qquad 2+48 = 50 $$
$$ \texttt{2 + 3 * 4\^2} = 50 $$
정답: 왼쪽부터 순서대로($2+3=5$, $5\times16=80$)로 읽으면 틀린다 — 우선순위가 지배한다.
2-1 · 함정 · Pitfalls

초보가 자주 틀리는 문법

⚠ = 와 == 혼동

= 는 대입, == 는 비교. if x = 5 는 문법 오류.

⚠ 삼각함수는 라디안

sin(90) 은 90° 가 아니다. 각도는 sin(90*pi/180) 또는 sind(90).

⚠ 세미콜론 누락

큰 배열을 ; 없이 실행하면 수천 줄이 쏟아진다 — 출력 억제 습관.

⚠ i·j 덮어쓰기

i=3 으로 쓰면 허수 단위가 사라진다. 반복 인덱스는 다른 이름 권장.

2-2 · 문제 · Motivation

MATLAB의 심장 · everything is a matrix

➡️
직관 — 100개의 데이터에 같은 연산을 하려면 보통 반복문을 돈다. MATLAB은 벡터·행렬을 통째로 한 번에 계산한다(벡터화). 연립방정식 $Ax=b$ 도 $x = A\backslash b$ 한 줄 — 이것이 수치해석에서 MATLAB을 쓰는 진짜 이유다.

벡터는 1차원 배열, 행렬은 2차원 배열. 생성·인덱싱·연산 세 가지만 손에 익히면 대부분의 수치 알고리즘을 코드로 옮길 수 있다. 특히 행렬곱 $*$ 과 원소별곱 $.\!*$ 의 구분이 핵심이다.

이번 절의 뼈대
콜론$\texttt{start:step:end}$ 등간격 벡터
인덱스$A(i,j)$ — 1부터 시작
연립방정식$x = A\backslash b$
네 가지 핵심 기호
$\texttt{:}$ 콜론 범위·전체 지정
$\texttt{.}$ 점 원소별 연산
$\texttt{'}$ 전치 행↔열 교환
$\backslash$ 백슬래시 $Ax=b$ 풀이
핵심
인덱스가 1-based 라는 점에서 C/Python(0-based)과 다르다 — off-by-one 실수의 단골 원인.

직접계산 · 행렬곱 $A*B$

$A=\begin{bmatrix}1&2\\3&4\end{bmatrix}$, $B=\begin{bmatrix}5&6\\7&8\end{bmatrix}$ 일 때 C = A * B(행렬곱)의 $C(2,1)$ 성분을 구하시오. (2행 $\times$ 1열의 내적)

$C(2,1)=\text{(2행)}\cdot\text{(1열)}$$=3\times5 + 4\times7$
행렬곱 정의
$$ C(2,1) = \sum_k A(2,k)B(k,1) = 3\cdot5 + 4\cdot7 $$
$$ C(2,1) = 15 + 28 = 43 $$
정답: 참고로 원소별곱 A.*B 였다면 $C(2,1)=3\times7=21$ 로 완전히 다르다.
2-2 · 함정 · Pitfalls

배열 연산에서 미끄러지는 곳

⚠ * 와 .* 혼동

* 는 행렬곱(차원 규칙), .* 는 원소별곱(같은 크기). 결과가 완전히 다르다.

⚠ 1-based 인덱스

첫 원소는 A(1). A(0) 은 오류 — C/Python 습관 주의.

⚠ inv(A)*b 남용

연립방정식은 A\b 가 더 빠르고 수치적으로 안정. 역행렬을 굳이 만들지 말 것.

⚠ reshape 열 우선

reshape(1:6,2,3) 은 열 방향으로 채운다 → [1 3 5;2 4 6].

2-2 · 코드 · MATLAB

연립방정식을 한 줄로 — $A\backslash b$

solve_system.m
% 2x + 3y = 8
% 4x +  y = 6
A = [2 3; 4 1];
b = [8; 6];
x = A \ b;             % 백슬래시 = LU 분해로 Ax=b 풀이
fprintf('x = %.2f, y = %.2f\n', x(1), x(2));
% x = 1.00, y = 2.00

% 크기·집계 함수
size(A)                % [2 2]  (행, 열)
sum([1 2 3])           % 6
det(A)                 % 2*1 - 3*4 = -10
Python 대비
같은 풀이가 NumPy에선 x = np.linalg.solve(A, b). MATLAB의 A\b 가 더 짧다 — 두 도구 모두 내부적으로 LU 분해를 쓴다.

연습 1 · 내적

$v=[1\ 2\ 3\ 4\ 5]$, $u=[10\ 20\ 30\ 40\ 50]$ 일 때 dot(v, u) 의 값은? ($\sum v_i u_i$)

$=\texttt{sum(v .* u)}$
계산
$$ 1\cdot10+2\cdot20+3\cdot30+4\cdot40+5\cdot50 $$
$$ 10+40+90+160+250 = 550 $$
정답: 내적 = 원소별곱의 합.
연습 2 · 행렬식

$A=\begin{bmatrix}1&2\\3&4\end{bmatrix}$ 의 det(A) 는? ($ad-bc$)

$1\times4 - 2\times3$
$$ \det A = 1\cdot4 - 2\cdot3 = -2 $$
정답: $\det\neq0$ 이므로 역행렬이 존재 → $A\backslash b$ 로 유일해.

2-3 · 문제 · Motivation

알고리즘 = 분기 + 반복 · until it converges

🔁
직관 — 수치해석의 거의 모든 방법은 "충분히 가까워질 때까지 반복"이다. 몇 번 반복할지 미리 모르므로 for(횟수 고정)가 아니라 while(조건 만족까지)가 심장이다. 이 구조가 이분법·Newton·Euler를 관통한다.

if 로 갈래를 나누고, for/while 로 반복한다. 반복을 재사용 가능한 함수로 묶으면 fzero, ode45 같은 내장 함수처럼 호출할 수 있다.

이번 절의 뼈대
분기$\texttt{if / elseif / else / end}$
고정 반복$\texttt{for i = 1:n}$
수렴 반복$\texttt{while error > tol}$
for vs while
for 횟수를 아는 경우 · 배열 순회
while 횟수를 모르는 경우 · 수렴 판정
break 반복 즉시 탈출
continue 이번 회차만 건너뜀
핵심
수치 반복은 항상 종료 조건 두 개 — 오차 tol 도달 또는 최대 횟수 max_iter 초과(무한루프 방지).

2-3 · 시연 · while 수렴

수렴할 때까지 반복 — 직접 돌려보기

while 의 진짜 쓸모는 수렴 반복이다. 아래는 $x_{n+1}=\cos(x_n)$ 을 계속 대입하는 고정점 반복($x=\cos x$). "다음 반복" 을 누르면 값이 한 점($\approx 0.7391$, 초록 점선)으로 빨려 든다 — 이것이 while error > tol 의 그림이다.

직접 계산while 종료 시점 예측 · 자동 채점
직접계산 · while 조건

다음 반복이 끝났을 때 n 은 얼마인가? $2^n$ 이 1000 을 처음 넘기는 최소 $n$ 을 구하는 코드다.

loop.m
n = 0;
while 2^n <= 1000
    n = n + 1;
end
$2^9=512$$2^{10}=1024$
추적
$$ 2^9 = 512 \le 1000\ (\text{계속}),\qquad 2^{10} = 1024 \gt 1000\ (\text{종료}) $$
$$ n = 10 $$
정답: 조건 2^n <= 1000 이 거짓이 되는 순간 n=10 에서 반복이 멈춘다.
2-3 · 함정 · Pitfalls

반복과 함수에서 막히는 곳

⚠ 무한 루프

수렴 조건이 안 맞으면 while 이 안 끝난다. 반드시 iter < max_iter 안전장치를.

⚠ 함수명 ≠ 파일명

function c = fahr2cel(f) 는 fahr2cel.m 으로 저장해야 호출된다.

⚠ 사전 할당 누락

반복 중 y(i)=... 로 배열을 키우면 느려진다 → zeros 로 미리 확보.

⚠ break vs continue

break 는 완전 탈출, continue 는 이번 회차만 건너뜀 — 헷갈리면 논리 붕괴.

% 다중 출력 함수 — 파일명 = my_stats.m

    s = std(data);         % 표준편차
end

% 호출
[m, s] = my_stats([10 20 30 40 50]);
% m = 30,  s = 15.8114

% 익명 함수 — 파일 없이 한 줄

f([0 1 2 3])                % [1 4 9 16]

연습 1 · 익명 함수

f = @(x) x.^2 + 2*x + 1; 일 때 f(3) 의 값은?

$3^2 + 2\cdot3 + 1$
$$ f(3) = 9 + 6 + 1 = 16 $$
정답: $(x+1)^2$ 이므로 $f(3)=4^2=16$.
연습 2 · 노름 함수

function n = my_norm(v); n = sqrt(sum(v.^2)); end 를 my_norm([3 4]) 로 호출하면?

$\sqrt{3^2+4^2}$
$$ \sqrt{9+16} = \sqrt{25} = 5 $$
정답: 유클리드 노름(벡터 크기).

핵심 · 실수

핵심 정리

  • for = 횟수 고정, while = 수렴까지(수치해석의 심장).
  • 종료 조건 2개: error < tol 또는 iter < max_iter.
  • 함수 = 재사용 모듈(파일명 일치), 익명 함수 @(x) = 한 줄 정의.

⚠ 자주 하는 실수

  • 안전장치 없는 while → 무한 루프.
  • 함수명과 파일명 불일치.
  • 익명 함수에 .^ .* 안 써서 벡터 입력 실패.
2-4 · 문제 · Motivation

숫자를 눈으로 · see the convergence

📈
직관 — 오차가 반복마다 얼마나 주는지, 수치해가 해석해에 얼마나 붙는지는 표보다 그래프가 한눈에 말한다. 특히 로그 스케일 그래프의 기울기는 곧 수렴 차수 — 다음 주부터 계속 쓸 무기다.

plot(x,y) 한 줄로 2D 그래프가 뜬다. 선 스타일·색·마커를 조합하고, hold on 으로 여러 곡선을 겹치며, xlabel/legend/grid 로 보고서용으로 다듬는다.

2-4 · 시연 · Log scale

로그 스케일 — 수렴 차수가 기울기로 보인다

스텝 $h$ 를 줄이며 오차를 재고 loglog(h, err) 로 그리면 직선이 나온다. 그 기울기가 곧 수렴 차수 $p$($\text{err}\sim h^p$). 아래 표는 $h$ 를 절반씩 줄일 때 오차가 어떻게 주는지다.

수렴 차수 읽기
  1. 여러 $h$ 에서 오차 $\text{err}$ 를 측정한다.
  2. loglog(h, err) 로 그린다(양축 로그).
  3. 직선의 기울기 = 수렴 차수 $p$.
  4. $h$ 절반 → 오차 $1/2^p$ 로 감소.
해석
기울기 $p=2$ 면 2차 수렴 $O(h^2)$ — $h$ 를 절반으로 줄이면 오차가 1/4. Newton·Simpson이 여기 해당.
$h$ 절반 → 오차(기울기 $p=2$)
스텝 $h$오차 err비율
0.10.0320—
0.050.00801/4
0.0250.00201/4
0.01250.00051/4
$h$ 를 반으로 줄일 때마다 오차가 $1/4$ → $\log$-$\log$ 기울기 2 → $O(h^2)$.
직접 계산수렴 차수 예측 · 자동 채점
직접계산 · 로그 기울기

스텝 $h$ 를 절반으로 줄였더니 오차가 $1/4$ 로 줄었다. loglog 그래프의 기울기, 즉 수렴 차수 $p$ 는? ($\text{err}\sim h^p$)

$\tfrac14 = \left(\tfrac12\right)^p$
방정식
$$ \frac{1}{4} = \left(\frac{1}{2}\right)^{p} \;\Rightarrow\; 2^{-2} = 2^{-p} $$
$$ p = 2 $$
정답: 2차 수렴 $O(h^2)$. 오차가 $1/2$ 로 줄면 $p=1$(1차), $1/8$ 로 줄면 $p=3$.
2-4 · 함정 · Pitfalls

그래프에서 자주 놓치는 것

⚠ hold on 누락

hold on 없이 다시 plot 하면 이전 곡선이 덮어써진다.

⚠ 성긴 x 축

x=0:1:10 처럼 성기면 곡선이 각져 보인다 → linspace(0,10,200).

⚠ 잘못된 스케일

지수적으로 주는 오차는 일반 plot 에선 안 보인다 → semilogy.

⚠ legend 순서

legend 이름은 plot 호출 순서와 같아야 한다 — 어긋나면 오해.

2-4 · 코드 · MATLAB

수치해 vs 해석해 겹쳐 그리기

euler_plot.m
% dy/dx = -y,  y(0)=1  →  해석해 y = e^(-x)
h = 0.5;   x_end = 4;   N = x_end / h;
x = zeros(1, N+1);   y = zeros(1, N+1);   y(1) = 1;

for i = 1:N                       % Euler 반복
    x(i+1) = x(i) + h;
    y(i+1) = y(i) + h*(-y(i));    % 다음 값 예측
end

xe = linspace(0, x_end, 200);
plot(xe, exp(-xe), 'c-', 'LineWidth', 2);  % 해석해(실선)
hold on;
plot(x, y, 'o--', 'Color', [1 .5 0]);       % 수치해(주황 점)
hold off;
xlabel('x');   ylabel('y(x)');
legend('Exact: e^{-x}', 'Euler (h=0.5)');
grid on;
이어지는 주
이 그림에서 주황 점(수치해)이 청록 곡선(해석해)에서 벗어나는 폭이 곧 오차다. $h$ 를 줄이면 붙는다 — 이것을 정량화하는 것이 다음 주제(미분방정식·오차 해석)다.
연습문제그래프·벡터 예측 · 자동 채점
연습 1 · 1차 수렴 판정

$h$ 를 절반으로 줄였더니 오차도 절반($1/2$)으로 줄었다. 수렴 차수 $p$ 는?

$\tfrac12 = \left(\tfrac12\right)^p$
$$ p = 1 $$
정답: 1차 수렴 $O(h)$ — Euler 방법이 여기 해당(느림).
연습 2 · linspace

s = linspace(0, 1, 5) 의 4번째 원소 $s(4)$ 는? (0~1 을 5개로 등분)

$[0,\ 0.25,\ 0.5,\ 0.75,\ 1]$
$$ s(4) = 0.75 $$
정답: 간격 $1/4=0.25$, 1-based 이므로 4번째 = $0.75$.
